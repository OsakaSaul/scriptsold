The graveyard

Every API tracked here carries a dated notice from the vendor. Status words are exact: ended (shut down), scheduled (still live, end date announced), moved (no end date published, never called shut down). Back to the paste box.

  • Proxycurl ended 2025-07-04

    The whole service was shut down. The vendor's founder post says LinkedIn filed a lawsuit in January 2025 and that closing Proxycurl was needed to comply with the settlement.

    Source notice, read 2026-11-23
  • Clearbit Logo API ended 2025-12-08

    The vendor's release notes say the public Logo API address is no longer available after 8 December 2025.

    Source notice, read 2026-11-23
  • Clearbit Enrichment moved

    Clearbit's home page says it has joined HubSpot, and its blog describes the replacement as enrichment inside HubSpot. No end date was published for the standalone enrichment API, so it is shown as moved, not as shut down.

    Source notice, read 2026-11-22
  • Bing Search APIs ended 2025-08-11

    Microsoft's lifecycle notice lists the Bing Search and Custom Search APIs as retired on 11 August 2025.

    Source notice, read 2026-11-23
  • Instagram Basic Display API ended 2024-12-04

    Meta's developer notice says the Basic Display API ends on 4 December 2024. The same hosts are also used by Meta's current Instagram APIs, so check which one your code uses.

    Source notice, read 2026-11-23
  • Reverse Contact legacy person routes ended 2026-10-13

    The vendor's platform update page says the legacy person routes return 410 Gone from 13 October 2026.

    Source notice, read 2026-11-23
  • Reverse Contact Activities ended 2026-07-01

    The vendor's platform update page says posts, comments and reactions were discontinued on 1 July 2026.

    Source notice, read 2026-11-23
  • DataForSEO Pinterest and Social Media APIs ended 2026-09-16

    DataForSEO's update notice says support for its Pinterest and Social Media APIs ended on 16 September 2026.

    Source notice, read 2026-11-23
  • Lusha Person API v2 scheduled 2026-11-30

    The vendor's guide says the v2 person call carries a Sunset header since 18 May 2026 and is retired after a six-month overlap. It is still live today.

    Source notice, read 2026-11-23
  • Google Custom Search JSON API scheduled 2027-01-01

    Google's overview page says the API is closed to new customers and that existing customers have until 1 January 2027 to move to another solution. It still answers today.

    Source notice, read 2026-11-23
  • Google+ API ended 2019-03-07

    Google's shutdown page says the legacy Google+ APIs were shut down on 7 March 2019.

    Source notice, read 2026-11-23
  • X API v1.1 search endpoints moved

    The X changelog entry of 28 September 2023 says the v1.1 search/tweets, users/search and geo/search endpoints were deprecated. The notice gives no removal date, so this is shown as moved, not as shut down.

    Source notice, read 2026-11-23
  • X API v1.1 statuses/filter stream moved

    The X changelog entry of 14 March 2023 says the v1.1 statuses/filter endpoint was deprecated. No removal date is given, so this is shown as moved, not as shut down.

    Source notice, read 2026-11-23
  • X API v1.1 legacy Direct Message endpoints ended 2018-09-17

    The X changelog entry of 17 September 2018 says the legacy Direct Message endpoints were fully retired. The newer direct_messages/events paths are not covered.

    Source notice, read 2026-11-23
  • X API v1.1 help/configuration ended 2021-06-18

    The X changelog entry of 18 June 2021 says the standard v1.1 GET help/configuration endpoint was retired.

    Source notice, read 2026-11-23
  • Instagram API Platform (legacy, api.instagram.com/v1) ended 2020-06-29

    Meta's developer blog says the Instagram Legacy API Platform was due to be disabled on 31 March 2020 and that, in a 30 March 2020 update, it was postponed by 90 days to 29 June 2020.

    Source notice, read 2026-11-23
  • Crunchbase API v3.1 ended 2021-01-29

    Crunchbase's release history says end of support for API v3.1 was 30 October 2020 and end of life 29 January 2021, after which it is no longer accessible. Crunchbase's Basic getting-started page also says the Basic API is no longer offered (no date given).

    Source notice, read 2026-11-23
  • Yahoo BOSS Search API ended 2016-03-31

    The Next Web (11 March 2016) reports Yahoo's notice that BOSS users must switch to Yahoo Partner Ads by 31 March 2016. The article does not use the word discontinued; the date is the vendor's switch-by date.

    Source notice, read 2026-11-23
  • Alexa Web Information Service and Top Sites APIs ended 2022-12-15

    SecurityWeek (6 May 2022) reports that the Alexa Top Sites and Web Information Service APIs were scheduled to be retired on 15 December 2022. The date comes from news coverage of the retirement notice, not from a page on the vendor site.

    Source notice, read 2026-11-23
  • FullContact v2 Company API ended 2022-06-30

    FullContact's migration page says that on 30 June 2022 it would sunset its legacy v2 Company API. The v2 Person API is not covered: the page gives no sunset date for it.

    Source notice, read 2026-11-23
  • LinkedIn open APIs (v1 people and companies) moved

    Computerworld (12 February 2015) reports that from 12 May 2015 LinkedIn offered only a handful of APIs for general use, and that only companies in its partner program would have API access. This is an access restriction, not a shutdown, so it is shown as moved.

    Source notice, read 2026-11-23
  • Pinterest API v3 and v4 moved

    Pinterest's developer community post (1 February 2023) says v3 and v4 endpoints would no longer be supported beginning July 2023 and that support moves to v5. It says unsupported, not switched off, so this is shown as moved.

    Source notice, read 2026-11-23
