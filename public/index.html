How it works

  1. 1

    Find the corpse

    It matches the host, the path, the auth style and SDK imports against a list of dated, sourced shutdown notices. A shared host alone is not enough.

  2. 2

    Check for a heartbeat

    A call is mapped only if the FoxAPIs endpoint is in the catalog snapshot with status live. Nothing is invented: no endpoint, no parameter, no field.

  3. 3

    Bring it back

    You get your file with the old call replaced, standalone JavaScript, Python and curl, a list of what changed, and a field-mapping table. A field FoxAPIs cannot fill comes back as null with the reason.

The graveyard

Every entry carries the date and the vendor's own notice. The status words are exact: ended, scheduled (still live, end date announced) and moved (no end date published, never called shut down). See the full graveyard page.

Try the replacement for real

The replacement code needs a FoxAPIs key in the environment variable FOXAPIS_KEY. A free key with welcome credits, no card, is at foxapis.com/trial. For what each call costs, see foxapis.com/pricing. The key is never written into the code Resurrect gives you.
