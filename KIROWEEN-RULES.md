# Kiroween 2026: rules checklist for this repository

Read from https://kiroween.devpost.com/rules and https://kiroween.devpost.com/ on 2026-11-25. The official rules win over this page.

Deadline: December 4, 2026, 2:00pm PST = December 5, 07:00 JST. No extensions. Aim to submit December 3.

Kiro credits (optional, up to 4,000): the request form closes December 1, 12:00pm PT = December 2, 05:00 JST. It needs your Kiro user ID or AWS account ID. Allow 48 business hours. The rules call it the Credit Request Form; the overview page says details are on the Resources tab.

Category: Resurrection ("Bring your favorite dead technology back to life. Reimagine obsolete tech with today's innovations or solving tomorrow's problems."). This project fits it.

Judging: first pass or fail (fits the theme, applies Kiro), then five equal criteria: Potential Impact, Technological Implementation (how well Kiro was used), Design, Innovation, Presentation.

Optional bonus prizes: Startup (you are a founder; LinkedIn profile and startup website); Social Blitz (a post that starts with #KiroweenHackathon26, judged partly on original rather than AI-written thoughts; link it in the form); Blog (a public post about Kiro and this build that says it is written for Kiroween 2026).

Check yourself: the rules say availability of Kiro features and models can differ by region and the entrant is responsible. Check this for Japan at https://kiro.dev (not checked here). The excluded countries listed in the rules do not include Japan.
